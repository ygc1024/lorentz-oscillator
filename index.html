Lorentz 진동자 실습판

감쇠 조화진동자 하나가 유전율 ε₁·ε₂를 만들고, 거기서 굴절률 n과 소광계수 κ가 따라 나옵니다. 파라미터를 움직이면서 네 곡선이 어떻게 함께 변하는지, 그리고 그 결과로 빛이 얼마나 반사·흡수·투과되는지를 한 화면에서 보세요.

쓰는 식

전자를 감쇠 조화진동자로 보고 (식 2.5) 강제진동 해를 구하면, 공명 하나짜리 매질의 유전율이 나옵니다. 여기서 ωp² ≡ Ne²/ε₀m₀ = (εst − ε∞)ω₀² 입니다.

식 2.15 / 2.16
ε₁ = ε∞ + ωp²·(ω₀²−ω²) / [(ω₀²−ω²)² + (γω)²]
ε₂ =      ωp²·(γω)  / [(ω₀²−ω²)² + (γω)²]

공명 근처(ω ≈ ω₀ ≫ γ)에서는 Δω = ω − ω₀로 두고 (ω₀²−ω²) ≈ −2ω₀Δω로 줄여 쓸 수 있습니다.

식 2.20 / 2.21
ε₁ = ε∞ − (εst−ε∞)·2ω₀Δω / [4Δω² + γ²]
ε₂ =  (εst−ε∞)· γω₀   / [4Δω² + γ²]

공명이 여러 개면 각 진동자의 기여가 그대로 더해집니다 (식 2.23). 이 앱의 「두 번째 공명」이 바로 j = 2인 경우입니다.

식 2.23
ε̃(ω) = ε∞ + Σj  ωpj² / (ω₀j² − ω² − iγj ω)

측정으로 얻는 양은 n과 κ입니다. ε̃ = (n + iκ)² 를 풀면

식 1.25 / 1.26
n = √( (√(ε₁²+ε₂²) + ε₁) / 2 )
κ = √( (√(ε₁²+ε₂²) − ε₁) / 2 )

흡수계수와 수직입사 반사율, 그리고 두께 d 시료의 (간섭을 무시한) 투과·반사는

식 1.19 / 1.29
α = 2κω/c ,   R₁ = [(n−1)² + κ²] / [(n+1)² + κ²]
연습문제 1.8
T = (1−R₁)²e−αd / (1 − R₁²e−2αd) ,   A = 1 − R − T

그래프에서 확인할 것

  • ε₂는 ω₀에 뾰족한 봉우리를 갖고 반치폭이 정확히 γ입니다. γ를 키우면 봉우리가 낮아지면서 넓어집니다 — 감쇠가 선폭을 만듭니다.
  • ε₁은 ω₀−γ/2에서 최대, ω₀+γ/2에서 최소가 됩니다. 공명을 지나면서 εst에서 ε∞로 떨어지고, 그 낙차가 진동자 세기 εst−ε∞입니다.
  • n은 대략 √ε₁을, κ는 대략 ε₂를 따라갑니다. 비교선을 켜서 확인해 보세요. n ≫ κ일 때만 정확히 맞고, 흡수가 아주 강한 ω₀ 부근에서는 어긋납니다.
  • 굴절률 효과가 흡수보다 훨씬 멀리 갑니다. 공명에서 멀어질 때 ε₂는 Δω⁻²로, ε₁의 변화는 Δω⁻¹로 줄어듭니다 — 투명한 영역에도 분산이 남는 이유입니다.
  • ε₁ < 0인 구간에서는 파동이 매질 안으로 들어가지 못해 반사율이 1에 가까워집니다. 이온결정 예시에서 보이는 잔류선(Reststrahlen) 띠가 그것입니다.
  • 흡수 A는 두께에 의존하지만 R, n, κ는 그렇지 않습니다. 두께 슬라이더만 움직여 보면 어떤 양이 물질의 성질이고 어떤 양이 시료의 성질인지 구분됩니다.
  • 빛의 수지는 세 가지로 볼 수 있습니다. 「누적」은 R + A + T = 1이라는 보존을, 「겹쳐」는 같은 축 위에서 세 스펙트럼의 크기 비교를, 「따로」는 각자의 모양을 보여줍니다. 특히 흡수가 아주 약할 때는 「따로」로 봐야 A의 봉우리 모양이 드러납니다 — 축 눈금 숫자로 실제 크기를 읽으세요.
  • 축이 자동으로 다시 맞춰지면 변화가 안 보입니다. 「축 고정」을 누르면 지금의 눈금이 그대로 붙박여, γ를 키울 때 봉우리가 실제로 내려앉는 것이 보입니다. 「기준 곡선 저장」을 함께 쓰면 이전 곡선이 점선으로 남습니다.
  • 공명이 둘이면 서로가 자입니다. 두 번째 공명을 켜고 한쪽 세기만 줄여 보세요. 절대적인 크기 대신 옆 봉우리와의 상대 비교로 변화를 읽게 되고, 두 공명 사이 구간에서 ε₁이 두 번 꺾이는 것도 보입니다.

해볼 것

답은 눌러서 확인
1. γ만 10배 키우면 ε₂의 봉우리 높이는 어떻게 되나?

ω₀에서 ε₂ = (εst−ε∞)ω₀/γ 이므로 정확히 1/10로 줄고, 폭은 10배가 됩니다. 봉우리 아래 넓이(진동자 세기)는 보존됩니다. 커서를 ω₀에 두고 γ를 움직이며 숫자로 확인하세요.

2. 「원자 기체」 예시에서 n의 최대·최소는 어디에 있나?

ω₀ − γ/2와 ω₀ + γ/2입니다. 이 예시(Na D₂선)에서 γ/2 = 50 MHz에 해당하고, 공명 기여분의 최댓값은 약 3.95 × 10⁻⁵입니다 (교재 예제 2.1). 값이 워낙 작아 n ≈ 1이지만 곡선 모양은 그대로입니다.

3. 왜 GaAs·NaCl 예시에서는 반사율이 1에 가까운 넓은 띠가 생기나?

ωTO와 ωLO = ωTO√(εst/ε∞) 사이에서 ε₁이 음수입니다. 그러면 n이 작고 κ가 커져서 R₁ = [(n−1)²+κ²]/[(n+1)²+κ²]이 1에 접근합니다. 빛은 흡수되는 것이 아니라 되튕겨 나옵니다. 두께를 키워도 이 띠의 반사율은 거의 그대로입니다.

4. 근사식(2.20/2.21)은 어디서부터 틀리기 시작하나?

토글을 켜고 보기 폭을 넓혀 보세요. |Δω| ≳ ω₀/10이 되면 (ω₀²−ω²) ≈ −2ω₀Δω 가정이 깨져서 날개 부분이 어긋나고, ω → 0 극한에서 ε₁이 εst로 수렴하지 않습니다.

5. 「유리」 예시에서 가시광 영역의 색분산은 어느 쪽이 큰가?

자외선 공명의 저주파 쪽 날개에 해당하므로 ε₁은 진동수가 높을수록 커집니다. 즉 파란빛의 n이 보라빛 쪽으로 갈수록 커지는 정상분산이고, 프리즘이 파란빛을 더 많이 꺾는 이유입니다.

6. 두 공명 사이에서 ε₁은 왜 ε_∞보다 큰가?

「이웃한 두 공명」 예시를 켜 보세요. 첫 공명의 위쪽 날개(음의 기여)와 둘째 공명의 아래쪽 날개(양의 기여)가 겹치는데, 가까이 있는 쪽이 이깁니다. 식 2.23처럼 각 진동자의 기여가 그냥 더해지기 때문이며, 낮은 진동수로 갈수록 지나온 공명이 쌓여 굴절률이 커지는 것(그림 2.6)도 같은 이유입니다.

7. 흡수 A를 최대로 만들려면?

반사가 너무 크면 빛이 들어가지 못하고, 두께가 얇으면 그냥 통과합니다. αd ≈ 1~3이면서 R₁이 작은 조건 — 보통 공명에서 살짝 벗어난 어깨 부분에서 A가 최대가 됩니다. 두께 슬라이더와 커서를 함께 움직이며 A의 봉우리가 어디로 가는지 보세요.
