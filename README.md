# Lorentz 진동자 실습판

Mark Fox, *Optical Properties of Solids* (Oxford, 2nd ed. 2010) **§2.2.1 그림 2.4**를
학생이 직접 그려보며 익히는 단일 파일 웹앱.

## 무엇을 보여주나

| 패널 | 내용 |
|---|---|
| ε₁ / ε₂ | 감쇠 조화진동자의 복소 유전율 (식 2.15 · 2.16, 또는 공명 근사식 2.20 · 2.21) |
| n / κ | 위 유전율에서 계산한 복소 굴절률 (식 1.25 · 1.26) |
| R / A / T | 두께 d 시료의 반사·흡수·투과 (식 1.19 · 1.29 + 연습문제 1.8의 다중반사 식) |
| 광선 도식 | 커서 진동수에서 빛이 어디로 가는지 |

조작 가능한 파라미터: ω₀, γ, ε_st − ε_∞, ε_∞, 시료 두께 d, 보기 폭(±Nγ).

## 대표 예시

- **교재 그림 2.4** — ω₀ = 10¹⁴ rad/s, γ = 5×10¹² s⁻¹, ε_st = 12.1, ε_∞ = 10
- **원자 기체 (Na D₂)** — 예제 2.1의 설정, n ≈ 1인 약한 진동자 극한
- **GaAs / NaCl 격자진동** — ε₁ < 0 구간에서 생기는 잔류선(Reststrahlen) 반사띠
- **유리의 자외선 공명** — 공명에서 멀리 떨어진 투명 영역의 분산
- **아주 센 진동자** — 금속에 가까운 넓은 반사띠
